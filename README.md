# COSMIC CONQUEST: THE COIL (3D test)

A high-detail faceted 3D containment defence set in the Cosmic Conquest
universe, rendered in the Neon Reliquary painted style. Zero dependencies,
ONE file: every mesh, texture and sound is generated at runtime from code.
WebGL2.

**Play:** <https://majieddd.github.io/cosmicconquest3dtest/>

- Open `index.html` directly (file:// works, no server, no network), or
  serve the folder with any static server.
- Fourteen towers, ten elemental reactions, twenty waves, four boards,
  five commanders, WebGL2, zero dependencies.
- No npm, no bundler, no framework, no image files, no audio files, no
  3D model files.

## Controls

| Key | Action |
|---|---|
| 1-9 | select a tower |
| click | place, or inspect a built tower |
| U / S | upgrade / sell the inspected tower |
| Q / E | commander abilities |
| Enter | call the next wave early |
| Space | cycle speed 1x 2x 4x |
| P | pause |
| drag / wheel | orbit / zoom |

## The refinement campaign

This build carries the five-round polish campaign documented in
[ROUNDS.md](ROUNDS.md): a rebuilt painted plate (dark ground, warm lit
lane), an industrial cooling-plant floor via procedural geometry, actor
core branding, hit squash-and-jolt reactions, camera impact punch,
two-pass beams with hot cores, and a live STAYS readout. Every round was
verified against the project's own 127-check gate (verify 79/79,
adversarial 48/48 on the final tree).
